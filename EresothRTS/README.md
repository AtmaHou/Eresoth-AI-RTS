# 厄瑞索斯 RTS · 第一阶段可玩 Demo（Eresoth RTS Phase 1）

对应《RTS对战游戏项目启动设计文档》M1 垂直切片的先行版：**纯代码生成，零美术资源，开箱即玩**。
当前版本 **v1.5.0**，详见 [CHANGELOG.md](CHANGELOG.md)。

## 代码导读

想快速理解各个脚本负责什么、游戏从哪里启动、玩家/AI 命令如何流转，请先看 [CODE_MODULE_GUIDE.md](CODE_MODULE_GUIDE.md)。

## 环境要求
- Unity 6（建议 6000.3 LTS，任意 6000.x 均可；打开时如提示版本不一致，选择你本机已安装的 Unity 6 即可）
- 无需任何第三方插件；代码编辑器用 Cursor/VSCode 均可

## 上手步骤

### 第 0 步：安装 Unity（仅首次需要）
1. 从 https://unity.com/download 下载并安装 **Unity Hub**
2. 打开 Unity Hub，进入 **安装（Installs）** 页，安装 **Unity 6**（建议 `6000.3 LTS`，任意 6000.x 均可；本工程使用 6000.3.2f1 制作）
3. 安装时无需勾选额外模块，无需任何第三方插件；代码编辑器用 Cursor/VSCode 均可

### 第 1 步：添加并打开工程
1. 解压本工程（如使用压缩包 `EresothRTS_Phase1.zip`）
2. 打开 Unity Hub → **添加（Add）→ 从磁盘添加项目（Add project from disk）** → 选择 `EresothRTS` 文件夹
3. 在工程列表中点击刚添加的 `EresothRTS` 用 Unity 6 打开（首次导入约 1~2 分钟，耐心等编译完成）
4. 如提示版本不一致，选择你本机已安装的 Unity 6 即可

### 第 2 步：生成场景并开始游戏
1. 等待编辑器右下角编译完成（无转圈动画）
2. 顶部菜单栏点击 **工具 → 生成RTS演示场景**
3. 点击编辑器正上方的 **Play（▶）** 按钮开始游戏

### 第 3 步：验证能正常游玩
- 左键点选单位，右键点地面应能移动；滚屏/缩放正常即环境无误
- 若报错或操作无响应，见下方"常见问题"

## 玩法
- **目标**：摧毁敌方主基地获胜；己方主基地被拆则战败
- **阵营**：开局面板可选 **人类 / 不死族**（另一方由 AI 操控）
- **操作**：
  - 左键：点选 / 按住拖动框选
  - 右键：点地面=移动 | 点敌人=攻击 | 农夫点树/水晶=采集 | 选中建筑时点资源=派空闲工人采集、点地面=设集结点
  - Ctrl+数字：将当前选中存为编队；按数字键召回（编辑器内若 Ctrl+1~5 被 Unity 窗口快捷键占用，可用 Alt+数字代替，打包后不受影响）
  - 双击己方单位：选中屏幕内所有同类型单位编队
  - WASD / 方向键 / 鼠标贴屏幕边缘：滚屏；滚轮：缩放；Q/E：旋转
- **经济**：农夫采木头、采魔法水晶 → 主基地训练更多农夫 → 攒木建兵营出兵；建筑右键资源可一键调派空闲工人，集结点压在资源上时新工人出厂即自动上工
- **开局设置**：每局开始前可选——地图随机（开=每局随机种子不同布局，关=固定种子可复现）与资源丰富度（贫瘠/标准/富饶，树木与魔法矿数量 ×0.6/×1/×1.8）；设置跨"再来一局"保留
- **建造**：主基地面板选建筑后进入放置模式，**自由选址**（需在主基地 32 格内、不与其他建筑/资源点重叠），绿预览=可建、红=不可建，右键/Esc 取消；同类建筑全场唯一，**箭塔**最多 8 座，**民居**可建多座
- **人口**：主基地提供 40 人口，每座**民居**（80 木）+15，**上限 100**（4 座民居到顶）；人口不足时训练按钮不可用，顶部资源栏实时显示 `当前/上限`
- **兵种（人类）**：步兵（兵营）/ 长弓手（弓箭场）/ 骑士（马厩）；循环克制：步兵克骑兵、远程克步兵、骑兵速度快克远程，克制伤害 +50%；远程攻击有飞行弹道
- **英雄**：每方限一位，兵营训练（300 木 + 150 矿）——人类 **骑士团长**（近战骑兵，650 HP，AOE 溅射）、不死 **死亡游侠**（远程，520 HP，攻击带 AOE）；均有 **攻击光环**（附近友军伤害 +25%，脚下金圈为范围）与更强数值；AI 也会训练英雄
- **自动反击**：单位被打会立即锁定攻击者反击并追击；击杀后继续自动索敌
- **防御与经济建筑**：**伐木场**使工人采集量 +50%；**箭塔**自动攻击射程 11 内敌人（攻 12）
- **科技**：兵营可研究攻防升级（各 2 级，每级 +15%，逐级的造价递增）；选中研究中的建筑可看进度
- **敌方（不死）**：地穴出骷髅兵并攀攻防科技、诅咒神殿出亡灵射手、死亡马厩出死亡骑士、同样会建伐木场与民居；兵力达标后分波进攻，波次规模递增。AI 有基本战术：基地遇袭会全军回防、派骑兵猎杀你落单的采集工人、按你的兵种构成训练克制兵种、你基地驻有重兵时先打部队再拆家

## 数值与扩展
- 所有兵种/建筑/科技/采集数值集中在 `Assets/Scripts/Common.cs` 的 `GameConfig`（`UnitDef` / `BuildingDef` / `TechDef` 三张表），改数值不用碰逻辑
- 地图生成在 `Game.BuildWorld()`：随机/固定种子与资源丰富度由开局设置面板（`MapSettings`）控制，树木与魔法矿数量/位置随种子变化

## 常见问题
- **报错 "InvalidOperationException: ... Input"**：Project Settings → Player → Active Input Handling 改为 `Input Manager (Old)` 或 `Both`
- **想从模板新建工程再拷代码**：只拷 `Assets/Scripts` 和 `Assets/Editor` 即可，同样执行第 4 步
