# 体验验证指南（v2.0 文字指挥 Demo）

> 本文说明当前版本（v2.0，D1 阶段）**能玩什么、怎么操作、如何验证**。
> 对应设计文档：《AI增强自然语言指挥实现计划》第 4、5、7 章中标注 ✅ 的能力。

---

## 1. 准备工作

### 1.1 配置 LLM（可选，推荐）

在项目根目录（`EresothRTS/` 文件夹内，`Assets/` 的上一级）创建 `llm_config.json`：

```json
{
  "base_url": "https://api.openai.com/v1",
  "api_key": "sk-你的密钥",
  "model": "gpt-4o-mini"
}
```

- 兼容任何 OpenAI 格式的接口（改 `base_url` 即可，如 DeepSeek、通义、本地 vLLM 等）。
- 该文件已被 gitignore，不会进版本库。
- **不配也能玩**：指挥台会自动使用本地关键词解析兜底，但只能识别模板化说法，泛化能力验证需要配 LLM。

### 1.2 打开演示模式（强烈推荐）

进入游戏后，按 **F9** 打开指挥面板，勾选**演示模式**并重开一局。演示模式会：

- 开局自带 12 个战斗单位（6 步兵 / 4 弓手 / 2 骑兵），自动编成**一军团、二军团**
- 兵营、靶场已建好，资源加倍
- 敌方 AI 进攻更激进（约 3 分钟就能体验完整剧情：指挥 → 接战 → 条件撤退 → 回防）

## 2. 基本操作

| 操作 | 说明 |
|---|---|
| 指挥台输入框 | 屏幕左下角，点击后打字，**回车发送** |
| 打字时 | WASD 镜头移动与框选自动禁用，鼠标点出输入框后恢复 |
| F9 | 指挥面板：军团状态、命令日志、战场动态、演示模式开关 |
| F10 | 一键自动编组（把现有战斗单位编成两个军团） |
| F1~F8 | 内置示例军令（用于无 LLM 时快速测试执行层） |
| 鼠标右键 | 手动指挥选中单位；该单位 8 秒内不受军团调度（手动接管） |

### 2.1 战争迷雾（v2.1 新增，默认开）

- **开局面板**：新增"战争迷雾：开/关"选项；**游戏内顶栏**也有"迷雾：开/关"按钮，可随时切换对比。
- 开启时为魔兽式双重迷雾：**未探索区域全黑**，**已探索但当前不可见区域半暗**（地形隐约可见），可见区域清晰。
- 关键规则：**看不见 = 不知道**——看不见的敌人整体隐藏（含血条）、无法右键点选；参谋态势摘要、条件军令（"遇到主力就撤"）、"敌方前线"全部只统计看得见的敌人。

## 3. 推荐验证清单

按顺序体验，每类给几个可以直接打的话术：

### 3.1 基础军事指挥

- `二军团去东矿`
- `一军团守家门口`
- `全军集结`
- `骑兵去骚扰`

**验证点**：参谋复述确认 → 军团整队行军 → F9 面板状态变为"执行中" → 完成后战报 ✔。

### 3.2 条件军令（核心特色）

- `二军团去东矿，遇到主力就撤`
- `一军团压上去，伤亡过半就撤回来`
- `全军待命，主基地血量低于一半就回防`

**验证点**：军令下达后部队正常推进；当敌人数量/伤亡比例触发条件时，部队自动执行撤退，战报播报"按预案撤退中"。

### 3.3 经济运营

- `造4个弓箭手`
- `攻击科技优先`
- `去中央矿开分矿`
- `六成工人去采木头`

**验证点**：F9 面板出现经济计划；训练进度随单位出产生效；工人采集比例按指令重新分配。

### 3.4 泛化能力（需 LLM）

随便说，验证"不是固定命令表"：

- `让老二去把东边那个矿场给端了，打不过就跑`
- `家里留点人看着，其他的都跟我压过去`
- `先别打，等他们过来`

**验证点**：模型把口语映射到正确的军团/地标/动作组合；无法识别时参谋追问（"您指一军团还是二军团？"），而不是瞎执行。

### 3.5 容错与兜底

- 断网或填错 API 地址后发指令 → 自动切本地解析，游戏不中断
- 说一句完全无关的话（如"今天天气不错"）→ 参谋回复"没听懂"并给出可执行提示
- 军团执行中用鼠标右键手动拉走某个单位 → 该单位 8 秒内不受军团调度，之后自动回归

### 3.6 紧急回防

- 故意不设防，等敌军打到主基地 → 最近军团自动接到回防军令（优先级最高），战报播报

### 3.7 战争迷雾（v2.1）

- 开局后环顾地图：只有基地周围清晰，其余全黑；派军团推进，走过的地方变成半暗（地形可见、敌人消失）
- `骑兵去东矿侦察` → 骑兵到达后东矿区域点亮，可见敌情出现在 F9 面板与参谋情报中
- `二军团去东矿，遇到主力就撤` → 推进途中敌军进入视野才触发计数，条件军令按"看得见的敌人"裁决
- 顶栏点"迷雾：关" → 全图恢复可见，便于对比"有无迷雾"两种指挥体验

## 4. 数据留痕

每次指挥的原文、战场态势、模型输出、执行结果都记录在项目根目录的 `command_log.jsonl`（已 gitignore）。可用于：

- 复盘"参谋为什么这样理解"
- 积攒评测数据，为将来端侧小模型蒸馏做准备

## 5. 已知限制（当前版本）

- 训练类计划可能多造 1~2 个单位（队列超发）
- 经济计划暂不支持条件触发（"木头低于100停兵"属 D2）
- 迷雾下敌方建筑只在可见时显示（不做魔兽式"最后所见"残影）；AI 对手仍全图感知（不偷看迷雾是后续公平性选项）
- 撤退中的部队若军团集结点随大部队移动，归队判断可能偏慢
